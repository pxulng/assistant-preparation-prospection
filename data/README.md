# Données

- `marques_synthetiques.csv` : 40 marques **fictives** (id M001 à M040), colonnes `jeu` (test ou validation), `piege` (aucun, chiffre_contradictoire, fait_ancien, info_manquante), `faits`, `fonctions_attendues`. Les faits ont été écrits par Claude, les fonctions attendues relues par l'auteur.
- `regie_fictive.md` : le vendeur fictif (Hexamédia), ses 4 sites et ses 4 offres, sans prix.
- `make_marques.py` : script qui génère le CSV.

Les noms de marques sont inventés ; toute ressemblance avec une marque réelle est fortuite.
